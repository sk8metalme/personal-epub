# personal-epub

個人で作成したリフロー型EPUBを管理するリポジトリです。iPhone／Apple Booksでの読みやすさを第一にし、Kindleでも確認できる構成を目指します。

## 制作ルール

- デジタル本の標準成果物はEPUB 3のリフロー型とする
- 画面幅・文字サイズに合わせて再配置できる本文、リンク付き目次、タップできる出典を用意する
- 固定ページ・印刷・提出が必要な場合だけPDFを併行して作る
- 出典、ビルド手順、EPUBCheckとアクセシビリティ検証の結果を成果物と一緒に残す

制作時は [.agents/skills/thinking-publication/](.agents/skills/thinking-publication/) の計画・執筆・検証手順を使います。
